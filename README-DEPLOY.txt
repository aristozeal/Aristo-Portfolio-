ARISTO PORTFOLIO — WEBSITE UPDATE

Included:
- index.html: cinematic introduction page
- main.html: main portfolio, with a Writings & Archives preview and updated navigation
- writings.html: separate searchable and filterable archive page containing all 8 works
- style.css, script.js, intro.css, intro.js: existing portfolio and intro assets
- writings.css, writings.js, archive-preview.css: archive page and homepage preview styles/scripts
- assets/archive/: original PDFs and source DOCX files, plus PDF viewing copies for the DOCX works

DEPLOY ON GITHUB (ANDROID)
1. Download this ZIP and extract it on your phone.
2. Open your GitHub repository in Chrome. Enable Desktop site if needed.
3. Open the repository root and choose Add file > Upload files.
4. Upload the CONTENTS of the extracted folder (not the enclosing folder). Keep the assets/archive folder structure intact.
5. If GitHub asks to replace existing files, replace them with these updated versions. Do not delete the assets/archive folder or its files.
6. Commit the changes to your main branch. GitHub Pages should publish automatically after deployment completes.
7. Open your site and test the intro page, Dive button, Archives navigation, filters, search, PDF previews and downloads.

IMPORTANT
- Keep all files in their supplied relative locations. The PDFs must remain inside assets/archive/.
- The DOCX originals are included for Vak Theory and Blade Runner 2099; their PDF versions are also included for in-browser reading.
- This package is intended to be uploaded to the repository root, alongside the existing website files.
